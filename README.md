# VideoCutTool

VideoCutTool 是一个视频创作辅助工具项目。当前已实现 AI 素材助手 MVP：输入文案后自动拆分分镜，并生成图片/视频搜索词与 AI 素材提示词。

## 本地运行

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```
